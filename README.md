## 🌟 주요 기능 (Key Features)

### 1. 💵 급여 역계산기 (`index.html`)
- **양방향 계산 지원:**
  - **세전 → 세후 (Gross → Net):** 기본급 및 비과세 수당 입력 시 4대보험과 소득세/지방소득세를 자동 차감하여 실수령액 산출.
  - **세후 → 세전 (Net → Gross):** 목표 실수령액을 입력하면 이분탐색(Binary Search) 알고리즘을 통해 세전 급여 역산.
- **국세청 근로소득 간이세액표 연동:** 부양가족 수 및 원천징수 비율(100%, 80%, 50%, 직접 입력)에 따른 정밀 세액 계산.
- **급여대장 누적 저장:** 계산 내역을 브라우저 내장 저장소(`localStorage`)에 저장하고 엑셀(`.xlsx`) 파일 내보내기 지원.

### 2. 📑 퇴직금 & 퇴직소득세 계산기 (`severance.html`)
- **평균임금 vs 통상임금 비교:** 3개월 급여/비과세, 연간 상여금·연차수당을 바탕으로 자동으로 근로자에게 유리한 기준 선택 산정.
- **2026년 퇴직소득세 산출:** 근속연수공제, 환산급여 공제, 기본세율(6%~45%)을 반영한 퇴직소득세 완벽 계산.
- **A4 규격 PDF 다운로드:** `html2pdf.js` 기반으로 단일 페이지에 최적화된 **'퇴직금 산정내역서'** PDF 출력 기능.

### 3. ⏱️ 중도 입/퇴사자 급여 일할 계산기 (`prorated.html`)
- **입/퇴사자 4대보험 부과 규칙 자동 적용:**
  - 월중 중도 입사자(1일 입사 제외) 및 중도 퇴사자(말일 퇴사 제외)의 국민연금·건강보험 면제(0원) 자동 판별 및 체크박스 제어.
- **날짜 편의 기능:** YYYYMMDD 8자리 연속 타이핑 자간 변환 및 당월 1일~말일 자동 세팅 기능.

### 4. 📋 급여대장 통합 관리 (`ledger.html`)
- 각 계산기에서 저장한 급여 항목 내역들을 한곳에서 조회, 개별/전체 삭제 및 **SheetJS 연동 `.xlsx` 워크북 내보내기**.
